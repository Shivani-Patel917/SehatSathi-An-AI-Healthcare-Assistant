# Sehat Sathi

```
sehat-sathi/
├── frontend/   React + Vite + Tailwind (port 5173)
└── backend/    Express dev stub (port 5000), replace with your real API
```

## Run

Terminal 1 (optional, only if you want the stub API):
```bash
cd backend && npm install && npm run dev
```

Terminal 2:
```bash
cd frontend && npm install && npm run dev
```

Open http://localhost:5173. In dev mode the login page has "Demo user" / "Demo admin" buttons that work without any backend.
